# تشغيل AlSafa Native 6 على Windows 10 (64-bit)

هذا المشروع **تجريبي** ويستخدم قاعدة SQLite مستقلة تماماً عن تطبيق الصفا المستخدم في المحل. لا تضع عليه نسخة بيانات المحل الحقيقية في أول تجربة.

## 1. بعد انتهاء تنزيل Android Studio

1. ثبّت Android Studio من المصدر الرسمي. البرنامج مجاني ولا يحتاج كراك.
2. افتح **More Actions → SDK Manager** (أو **Tools → SDK Manager**).
3. ثبّت **Android SDK Platform 34** و **Android SDK Build-Tools 34.0.0** و **Android SDK Platform-Tools**.
4. افتح **Settings → Build, Execution, Deployment → Build Tools → Gradle** واختر **Embedded JDK**. المشروع يستخدم Java 17.
5. افتح مستودع GitHub الخاص بك على الفرع **native6-development**، ونزّل ZIP للفرع ثم فك الضغط. يجب أن يكون المشروع الكامل، وليس ملف Kotlin منفرداً.
6. من Android Studio اختر **Open** وحدد مجلد **native6** الذي يحتوي على `settings.gradle.kts` (لا تختَر المجلد الأعلى).
7. انتظر انتهاء **Gradle Sync**. التحميل الأول للمكتبات يحتاج إنترنت على الكمبيوتر فقط؛ التطبيق نفسه يعمل دون إنترنت.

## 2. إخراج APK تجريبي

افتح مجلد `native6` في مستكشف ملفات Windows، ثم شغّل `build-windows.bat`. يمكن تشغيله أيضاً من Terminal:

```bat
cd native6
build-windows.bat
```

السكربت يبني التطبيق أولاً ثم يشغّل الاختبارات. إذا نجح الاثنان، ستجد الملف هنا:

```text
native6\app\build\outputs\apk\debug\app-debug.apk
```

**لا تستخدم APK التجريبي للمبيعات الفعلية** قبل مراجعة النتائج والنسخ الاحتياطية والوظائف على التابلت.

## 3. إذا ظهرت مشكلة

السكربت يحفظ التفاصيل في:

```text
native6\build-output.log
```

أرسل ملف السجل أو نص الخطأ من Android Studio. إذا بُني APK لكن فشلت الاختبارات، سيظهر تحذير صريح؛ لا تعتمد النسخة في المحل.

إذا ظهرت مشكلة في SDK، تأكد أن Android Studio ثبّت منصة 34 وأن المسار المعتاد هو:

```text
%LOCALAPPDATA%\Android\Sdk
```

## 4. أول تجربة على التابلت

ابدأ ببيانات اختبار فقط: أضف صنفاً، نفّذ بيعاً، سجّل قبضاً، جرّب مرتجعاً واسترداداً، ثم جرّب الموردين والصناديق والإقفال والنسخ الاحتياطي. يجب التأكد من بقاء العملات USD وTRY وSYP منفصلة، ومن عدم تغير البيانات عند رفض أي عملية.

**عندما ينتهي تثبيت Android Studio أخبرني، وسنستخدم سجل البناء الحقيقي لإصلاح الأخطاء بدل التخمين.**
