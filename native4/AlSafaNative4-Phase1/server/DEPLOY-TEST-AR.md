# نشر خادم اختبار Native 4

هذا المجلد يعرّف دالة واحدة فقط: `submitCommand` في منطقة `europe-west1`.

## حدود الأمان

- لا توجد هنا قواعد Firestore ولا إعدادات استضافة، لذلك النشر لا يستبدل قواعد مشروع الصفا الحالي ولا يلمسها.
- الخادم يقبل `TEST` فقط. كل الأنواع التجارية مرفوضة صراحةً حتى يكتمل معالجها الذري.
- لا يجوز اختيار مشروع Firebase الإنتاجي عشوائياً. الأفضل مشروع اختبار مستقل قبل أي ربط نهائي.

## ما يلزم قبل النشر

1. مشروع Firebase اختبار مستقل.
2. تفعيل Cloud Functions وFirestore وAnonymous Authentication لهذا المشروع.
3. حساب يملك صلاحية نشر Functions إلى المشروع الاختباري.

بعد ذلك فقط يكون أمر النشر:

```bash
firebase use <test-project-id>
firebase deploy --only functions:native4-command-server
```

لا تُنشر هذه الدالة إلى مشروع بيانات الصفا الحالي في هذه المرحلة.
