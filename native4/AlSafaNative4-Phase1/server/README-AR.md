# خادم أوامر AlSafa Native 4

هذا الخادم لم يُنشر بعد ولا يملك أي صلاحية تشغيلية على بيانات الصفا الحية.

## الحماية الحالية

- يقبل الشكل الكامل للأمر فقط.
- يحفظ إيصالًا ثابتًا باسم `operationId`؛ إعادة الإرسال ترجع نفس النتيجة ولا تكرر العملية.
- يسجل رقم مراجعة متسلسل وحدث تغيير صغير.
- لا يقبل في هذه المرحلة إلا `TEST`.
- جميع أوامر البيع والصيانة والشراء والخزائن ترفض صراحةً حتى تُبنى معالجاتها الذرية وتُختبر.
- تحتوي `firestore-native4.rules` على قاعدة منع كاملة للقراءة والكتابة المباشرة من التطبيق لمساحة Native 4؛ الخادم فقط هو الذي يملك مسار الكتابة.

## قبل النشر

1. إنشاء مشروع Firebase تجريبي منفصل.
2. تفعيل المصادقة وتحديد أجهزة المتجر المسموح بها.
3. اختبار `TEST` بين هاتف وتابلت.
4. بناء معالج `SALE` كاملًا: فاتورة + حركة مخزون + حركة خزنة + تدقيق في معاملة واحدة.
5. عدم نشر أي دالة على مشروع الصفا الحي قبل اجتياز الاختبارات.

## تنبيه نشر القواعد

ملف القواعد مصدر جاهز للمشروع الاختباري فقط، وهو غير مضاف إلى `firebase.json` حاليًا. لا يُنشر تلقائيًا ولا يغيّر قواعد مشروع الصفا الموجود.
