# Native 4 migration branch

هذه الفرع مخصص فقط للنظام التجريبي الجديد Native 4.

- Package التجريبي: `com.alsafa.native4.test`
- لا يقرأ أو يعدّل `com.alsafa.watch` أو بياناته.
- لا تُنقل أي بيانات متجر إلى هذا الفرع أو التطبيق قبل اكتمال اختبارات المزامنة.
- هدف البناء الأول: إنشاء APK تجريبي منفصل عبر GitHub Actions، ثم اختباره على الهاتف والتابلت.

## قواعد الأمان

1. كل عملية تملك `operationId` فريدًا.
2. الطابور المحلي لا يحذف العملية قبل تأكيد الخادم.
3. لا يعتمد الاستقبال على بقاء شاشة التطبيق مفتوحة.
4. لا توجد مزامنة لقوائم المنتجات كاملة.
5. لا يحق لجهاز فارغ أن يحذف بيانات جهاز آخر.

لن يصبح هذا الفرع هو التطبيق الأساسي قبل نقل مدروس، نسخة احتياطية نهائية، والتحقق من أعداد البيانات.
