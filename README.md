# AlSafa Accounting

أرشيف خاص كامل لتطبيق محاسبة **الصفا للساعات**.

- محفوظة الإصدارات من **v3.9.63 إلى v3.9.77**.
- لكل إصدار APK موقّع وحزمة SOURCE قابلة لإعادة البناء.
- v3.9.67: لم تكن حزمة SOURCE الأصلية موجودة، لذلك أضيفت حزمة مستخرجة من APK الأصلي وموضحة بالاسم.
- v3.9.77: نسخة **SAFE-CLOUD-RECOVERY** للاستعادة فقط، وليست النسخة اليومية بعد اكتمال الاستعادة.

راجع [فهرس الإصدارات](ARCHIVE_INDEX.md) لمعرفة الترتيب والحالة وطريقة التجميع.

## بنية الأرشيف

releases/v3.9.xx/
