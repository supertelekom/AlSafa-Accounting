# AlSafa Accounting

نسخة محفوظة كاملة من تطبيق محاسبة **الصفا للساعات**.

## النسخة الحالية

- الإصدار: `v3.9.77-SAFE-CLOUD-RECOVERY`
- النوع: نسخة استعادة سحابية آمنة
- الحالة: مخصصة لاستعادة البيانات من Firebase مع إيقاف الرفع لحماية البيانات من الكتابة الفارغة.
- هذه ليست النسخة التشغيلية اليومية بعد اكتمال الاستعادة.

## الملفات

- `releases/v3.9.77/AlSafaAccounting-v3.9.77-SAFE-CLOUD-RECOVERY-SOURCE.zip` — حزمة المصدر الكاملة المستخدمة للبناء.
- `releases/v3.9.77/AlSafaAccounting-v3.9.77-SAFE-CLOUD-RECOVERY-SIGNED.apk` — نسخة Android الموقعة.
- `releases/v3.9.77/SHA256SUMS.txt` — بصمات التحقق.

## الأمان

مفتاح توقيع AlSafa الدائم، كلمات المرور، وملفات معلومات التوقيع غير محفوظة في GitHub. يجب الاحتفاظ بها منفصلة وآمنة.

## ملاحظة البناء

الحزمة المصدرية هي مشروع APK مفكوك/قابل لإعادة البناء وليست مشروع Android Studio تقليديًا بـ Gradle. تحتوي على واجهة التطبيق، منطق المحاسبة، موارد Android، الطبقة الأصلية، وملفات ML Kit.
