# AlSafa Native 7 — UI-first reconstruction

Independent native Kotlin Android project. Native 6 is not modified. Phase 1 recreates the original tablet app UI from v3.9.359 assets, with no WebView, network, Firebase, or database writes. Screens are preview-only until their original interaction behavior is verified. Never treat mock balances or invoice actions as operational accounting.

Open the `native7` directory in Android Studio. The original reference is `AlSafaAccounting-v3.9.359-TABLET-PARTNER-DATE-REPORT-FIX-SOURCE.zip` (not bundled). Do not run GitHub Actions.
